# OpenCord

**Open-source alternative to Discord — community-first, privacy-respecting, self-hostable communication for everyone.**

OpenCord is a modern real-time chat and voice platform built as a free and open alternative to proprietary communication tools. It aims to give developers, communities, gamers, and teams full control over how they communicate — without vendor lock-in, invasive tracking, or closed ecosystems.

---

## ✨ Features

- 💬 Real-time text messaging  
- 🎙️ Voice channels  
- 📹 Video calls *(planned)*  
- 🧵 Threaded conversations  
- 👥 Community servers & channels  
- 🔐 End-to-end encryption *(planned)*  
- 🌐 Self-hostable deployment  
- 🤖 Bot & plugin ecosystem  
- 📂 File sharing and media support  
- 🎨 Custom themes and personalization  
- ⚡ Fast, lightweight, modern stack  

---

## 🚀 Why OpenCord?

Most communication platforms are:

- Closed-source  
- Hard to self-host  
- Privacy-invasive  
- Expensive at scale  
- Controlled by centralized companies  

OpenCord is built to be:

- ✅ Open Source  
- ✅ Community Driven  
- ✅ Developer Friendly  
- ✅ Privacy First  
- ✅ Extensible  
- ✅ Self-Hostable

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/yourusername/open-cord.git

# Move into project
cd open-cord

# Install dependencies
npm install

# Run development server
npm run dev
```
